# Project: Personal Blog and Website

## General Description
- This project uses the rust-based static site generator Zola
- Blog posts and articles and pretty much any content is in the Markdown format
- It uses the theme called "Duckquill"
- To build the site, use the cli command from flatpak `flatpak run org.getzola.zola [OPTIONS] <COMMAND>
  - You can run `flatpak run org.getzola.zola help` to learn about available commands

## Project's structure
- Configuration is in the `config.toml` file
- Content for the blog is under the `content/blog` directory
- The theme and templates used to build the blog is under the `themes/duckquill`
